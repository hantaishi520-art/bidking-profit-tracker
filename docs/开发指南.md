# 开发指南

> 面向本项目的开发者与 AI 助手。环境约定、构建、测试、发布流程的唯一权威文档。
> 接口契约见 `docs/api-contract.md`；历史决策归档在本地 `docs/history/`（不入库）；协作纪律见根目录 `AGENTS.md`。

## 一、目录结构约定

```
项目根/
├── BidKing解析器.exe / BidKing远程助手.apk   # 构建产物（不入库）
├── item_prices.db / result*.json / silver_cache.json / 生涯数据库/   # 运行数据（不入库）
├── .bidking_sec.bin / .bidking_pass / .ngrok_token.enc / .bidking_launcher.json  # 凭据（绝不入库）
├── README.md / 安全须知.md                    # 面向使用者
├── AGENTS.md                                  # AI 协作守则（改代码前必读）
├── docs/
│   ├── 开发指南.md（本文）
│   ├── api-contract.md                        # 现行接口契约（按接口组织）
│   └── history/                               # 历史交接文档归档（只增不改；不入库）
├── src/                                       # 全部 PC 端源码与内嵌资源
│   ├── bidking_launcher.py                    # exe 入口（解析→建库→起服务→开页面）
│   ├── serve.py                               # 本地服务器 + 全部 /api
│   ├── bidking_parser.py                      # 日志解析核心（S2C_89 + S2C45 双源合并）
│   ├── winlaunch.py / winsec.py               # Windows 窗口操作 / 安全存储（PBKDF2+DPAPI）
│   ├── build_nuitka.py                        # 打包（含构建前检查 + 价格配置种子）
│   ├── bidking_*.html + item_prices.csv + v233_items.json + ngrok.exe   # 内嵌资源
│   ├── item_prices_seed.db                    # 打包时的价格配置快照（构建产物，不入库）
│   └── tests/
│       ├── run_tests.py                       # 一键回归
│       ├── test_*.py                          # 源码级自测（临时端口+临时目录）
│       └── manual_*.py                        # 需真 exe 的手动验收（发布前跑）
├── app-android/                               # 安卓端（Kotlin WebView 壳）
└── 最终交付/                                  # 对外发布三件套（exe/apk/使用说明）
```

命名纪律：测试文件 `test_*.py`；需要真环境的验收脚本 `manual_*.py`；临时脚本用完即删；**禁止** `.bak`/`.new` 文件入库。

## 二、环境与版本约定

**版本号规则**：两端独立编号——PC 端改 `src/serve.py` 的 `APP_VERSION`（页脚/接口/启动打印共用）；APK 改 `app-android/app/build.gradle` 的 `versionName`（App 标题自动带上）。发版时两端一起 bump。

| 项 | 路径/值 |
|---|---|
| Python（打包/测试） | `<你的 Python 3.10+ 路径>`（本机构建实测 3.13） |
| Node（JS 语法检查） | `~/.workbuddy/binaries/node/versions/*/node.exe`（打包脚本自动探测） |
| Gradle | `~/.gradle/wrapper/dists/gradle-8.11.1-bin/eac4u065zwes5phgltp5f9b9e/gradle-8.11.1/bin/gradle.bat` |
| adb（模拟器） | `/d/game/Mobile-version-barcode-scanner/android-sdk/platform-tools/adb.exe`（MuMu：emulator-5554） |
| 游戏日志 | `C:\Users\<用户名>\AppData\LocalLow\laolin\BidKing\Player.log` |
| 端口 | 生产 8766 / 源码级测试 8799 |

## 三、构建

### PC exe
```
python src/build_nuitka.py
```
打包前自动执行（失败拒绝打包）：
1. 回归测试 `src/tests/run_tests.py`
2. 4 个内嵌网页的 `<script>` 块 `node --check`

打包时把**当前** `项目根/item_prices.db` 内嵌为价格配置种子（`item_prices_seed.db`）——改完价格想让新配置随包生效，重新打一次包。

- 若报 PermissionError：先 `taskkill /F /IM "BidKing解析器.exe"`（文件被运行中的实例锁定）。
- 打包前确认 8766 无僵尸监听：`netstat -ano | grep :8766`。

### 安卓 APK
```
cd app-android
gradle.bat :app:assembleRelease
cp app/build/outputs/apk/release/app-release.apk ../BidKing远程助手.apk
cp app/build/outputs/apk/release/app-release.apk ../最终交付/BidKing远程助手.apk
```
签名密钥 `app-android/bidking-release.keystore` —— **丢失则永远无法覆盖安装升级，务必另行备份**。

## 四、测试

```
python src/tests/run_tests.py     # 一键回归（~40 秒，临时端口+临时目录，不碰真实数据）
```

| 测试 | 覆盖 |
|---|---|
| test_auth_peer.py | 来源三级（local/lan/public）、鉴权矩阵、XFF 防伪造、配对全流程、开关矩阵 |
| test_launch_gate.py | 启动闸（local/lan 过、public 受开关控制） |
| test_public_gate.py | 公网准入（强制配对、敏感静态 401、browser_token 一次性、令牌权限边界） |

发布前手动验收（先在临时目录跑真 exe `--serve`）：
- `manual_verify_exe.py` —— 局域网地址/信任/页面文案
- `manual_verify_gate_exe.py` —— 公网闸（注意：会真实调用 /api/launch，先确保配置指向不存在的路径！）
- `manual_e2e_app_flow.py` —— 模拟 App 完整连接动作

## 五、发布清单

1. `git commit`（改动先行）
2. `python src/build_nuitka.py`（自带检查）→ 产物自动部署到根目录
3. APK 如有改动：gradle 构建 → 拷贝到根目录
4. 同步两个文件到 `最终交付/`：`BidKing解析器.exe`、`BidKing远程助手.apk`
5. `最终交付/使用说明.md` 如有行为变化同步更新
6. 发给别人前，自己这台机器跑 `BidKing解析器.exe --prepare-share` 清理凭据（只发 exe/apk/使用说明，绝不含 `生涯数据库/`、`.bidking_*`、`.ngrok_*`）
