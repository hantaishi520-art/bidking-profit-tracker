# BidKing 竞拍盈亏统计工具 · 使用说明

> 本文件夹是**可直接分享的完整成品**：电脑端解析器 + 手机端远程助手 + 本说明。
> 不含任何个人数据，可放心发给他人。

---

## 这套工具是干什么的

《BidKing》游戏每局会产生一份日志文件（`Player.log`）。这个工具负责：
- **电脑端**：把日志解析成「竞拍盈亏」报表（每局拿仓/未拿、盈亏、拍品价值、库存道具等），用网页展示。
- **手机端**：远程看同一份报表 + 库存低时手机弹通知 + 远程让电脑启动「竞拍之王全自动估价器.exe」。
  - 已移除：旧版的「远程刷新数据 / 远程退出程序」，要刷新战绩请回到电脑端点「实时刷新」。

全程本地运行，数据不经过任何云端服务器。

## 一、电脑端（第一次使用）

1. 把 `BidKing解析器.exe` 放在**任意文件夹**（建议单独建一个文件夹放它，因为运行时会自动创建数据库文件）。
2. **双击**运行它，程序会自动打开浏览器并显示报表页面。
3. 如果页面上显示的玩家不是自己，在「玩家 UID」输入框手动输入自己的 UID。
4. 点击「实时刷新」，程序会自动查找游戏日志（默认位置：`C:\Users\你的用户名\AppData\LocalLow\laolin\BidKing\Player.log`）并解析出战绩。
5. 以后每次玩完，点「实时刷新」即可看到最新结果。

> 如果自动找不到日志，把 `Player.log` 复制到 `BidKing解析器.exe` 同目录再刷新。

### 电脑端常用功能
- 浅色/深色切换、盈亏颜色切换（红盈绿亏 ⇄ 绿盈红亏）
- 收益走势/拍品价值/银币数量 三个图表切换
- 统计卡片：场次、拿仓率、盈亏、银币
- 按地图类型筛选（快递/仓库/集装箱/别墅/残骸/拍卖会/竞拍之巅）
- 「其他电脑访问」：同一局域网内另一台电脑用浏览器打开显示的地址，也能看报表
- 「🌐 公网访问」：ngrok 免费账号自带一个**永久域名**（ngrok 免费账号自动分配一个专属固定域名），地址一般不变，手机 App 里填一次即可
- **「🚀 远程启动电脑程序」弹窗**：可远程启动「竞拍之王全自动估价器.exe」。
  - 路径填写：点**「📂 浏览…」**按钮，电脑端会弹出系统文件选择框，选好自动保存（不用手敲路径）。
  - 留空「搜索目录」则自动在桌面按文件名搜索；保存失败会给出具体原因。
  - 说明：旧版的「远程刷新数据 / 远程退出程序」入口已移除，要刷新战绩请回到电脑端点「实时刷新」。
- **「历史战绩」按钮**：游戏重启后报表局数变少时，程序会把上一批完整战绩自动存进 exe 同目录的 `历史快照/` 文件夹。点「历史战绩」会弹出列表（如「9月4日 08:16」），选一份即可**续看上次的记录**；完整累计战绩仍在「生涯」页，不丢。

### 🔐 安全与配对（新增，只有这台电脑能看到）
> **同一 Wi-Fi（局域网）的手机/电脑：不需要配对**——填对访问密码即可连接（未设密码则直接连），功能全开。
> 以下防护只针对 **ngrok 公网访问**：公网设备必须过"三关"——**密码（你知道）+ 电脑上点「同意」（你做）+ 设备密钥（你有）**。
> 这样即使密码被别人猜到，对方也过不了第二关，你的电脑不会被陌生设备连上。

- 页面中间的「🔐 安全与配对」面板（只有本机浏览器能看到）：
  - **待处理请求**：当有设备通过**公网**发起配对时此处会出现卡片（设备名/型号/来源 IP），点「同意」即完成配对；点「拒绝」则驳回。
  - **已配对设备**：列出通过公网配对过的设备，可随时「撤销」——撤销后那台设备立即失效，需重新配对。
  - **安全开关（只对公网生效）**（默认值见括号）：
    - 公网新设备必须配对后才能查看数据（开；局域网无需配对）
    - 允许公网未配对的旧版 App 只读查看（开，方便朋友先看）
    - 允许公网手机远程启动估价器（**关**——需要时自己打开；局域网手机不受此限制）
    - 公网访问（ngrok）需已设密码且已配对（开）
- **换电脑/拷贝文件夹后**：程序会自动检测到，并**自动重置密码与配对**（你的战绩数据**不受影响**），页面顶部会显示一条黄色提醒，重新设置密码即可。

## 二、手机端（配合电脑端使用）

1. 把 `BidKing远程助手.apk` 传到手机（微信/QQ/U盘均可），点击安装。
   - 若提示「未知来源」，在设置里允许安装此应用。
2. 打开 App，点击底部「＋」添加解析工具：
   - **名称**：随便起一个，如「我的电脑」
   - **地址**：填电脑端网页顶部显示的局域网地址，形如 `http://192.168.x.x:8766`（这个地址在电脑网页顶部「另一台电脑访问」处可以看到）
   - **密码**：如果电脑端设置过访问密码，在这里填同一个密码；没设置就留空
3. 添加保存后自动连接，即可在手机上：
   - 查看竞拍盈亏报表、生涯统计、道具价格表
   - **生涯页秒开（2026-08-30 起）**：生涯数据缓存在手机本地，之后打开只拉新增的对局（几 KB），不再每次全量下载几分钟；首次打开仍需完整下载一次
   - **连接保持 / 报表页秒开（2026-08-31 起，App v1.11）**：
     - App 切到后台再回来**不再需要重新连接**；手机内存紧张把 App 回收后重开，也会自动静默恢复，不用你操作
     - 添加了**多个解析工具**时，底部来回切换是**秒切**（立即显示上次的页面，后台自动校验连接）
     - **报表页**也和生涯页一样把数据缓存在手机本地：重开 App 立刻显示上次的战绩，然后自动检查更新；电脑没开机时也能看上次的数据
     - 修复一个老毛病：点过「启动估价器」后，切后台回来状态栏可能永远卡在「启动中：idle」、看起来像连不上——已修
   - 库存道具少于 10 个时收到手机通知
   - 电脑端点了「实时刷新」后，手机会自动同步到最新战绩（约 10 秒内）
   - 底部红色「启动估价器」按钮：让电脑启动「竞拍之王全自动估价器.exe」并自动点掉卡密验证弹窗；程序已在运行时只置顶不重复开；启动后 4 分钟内失败会手机通知提醒（每次失败都是独立一条通知）
   - **卡密自动确认不打扰你**：采用「后台按键」方式——按键消息只投递给卡密窗口本身，不会跑到你正在用的程序里。所以你全屏打游戏时用手机启动估价器，游戏不会收到任何误触按键。万一自动点不掉，手机会提示「需要到电脑上手动点确定」。
   - **🏠 同一 Wi-Fi 直连，无需配对**：手机和电脑在同一个家里/办公室 Wi-Fi 下时，填对地址和密码（若设了密码）即可直接连上，功能全开，不需要电脑端点「同意」。
   - **🔐 什么时候才需要「配对」？** 只有通过 **ngrok 公网地址**（人不在家、用流量访问家里电脑）连接时，才需要到电脑报表页「🔐 安全与配对」里点「同意」。配对成功后手机改用设备密钥登录，密码不再在网络上传输；电脑端也可以随时「撤销」某台设备。
   - **✅ 同一台设备只需同意一次（2026-08-30 起）**：配对过一次后，就算你删除服务器重新添加、地址变了（如 ngrok 域名变化）甚至卸载重装 App，只要访问密码正确就会自动重新连上，不需要再到电脑端点「同意」。电脑端点「撤销」的设备才会重新要求配对。
   - **连接失败时看提示**：App 会显示具体原因（密码错误 / 电脑没开机或解析器没运行 / 地址不对等）。地址不确定时，先在电脑网页顶部找到「另一台电脑访问：http://192.168.x.x:8766」再填。

> 手机和电脑必须在**同一个 Wi-Fi/局域网**下。「另一台电脑/手机访问」打不开时，检查电脑防火墙是否放行端口 `8766`。

## 三、常见问题

| 问题 | 解决办法 |
|---|---|
| 双击 exe 没反应 | 先确保运行了杀毒软件没有拦截；右键「以管理员身份运行」再试 |
| 网页打不开 | 确认 exe 还在运行；刷新浏览器 |
| 手机连不上电脑 | ① 同一 WiFi；② 电脑防火墙放行 8766 端口；③ 地址别漏 `http://` 结尾的 `:8766` |
| 报表显示「暂无对局数据」 | 电脑端还没解析出结果，点电脑网页的「实时刷新」 |
| 手机重进 App 连不上 | 确认电脑 exe 仍在运行；点底部服务器名可重连 / 弹窗里改地址 |
| **报表突然显示 0 局 / 局数变少** | 不是你没打，是游戏重启后旧日志被改名存档了（见下方「⚠️ 一个要知道的坑」），完整战绩去「生涯」页看 |

## 四、端口与数据说明（想深入了解才看）

- 默认端口 **8766**，可改：命令行运行 `BidKing解析器.exe --serve` 后按提示操作。
- 运行目录下会自动生成：
  - `生涯数据库/career.db`：永久累积的生涯战绩（**请勿删除**，是最重要的数据）
  - `item_prices.db`：你在页面里自定义修改过的物品价格（首次运行会自动带上作者已调好的价格配置，可直接用或自行调整；你的修改不会被覆盖）
  - `result.json`：最近一次解析结果（每次刷新自动重写）
  - `silver_cache.json`：银币走势采样缓存（自动生成，删了会重建）
- 浏览器访问地址一律走 exe 提供的本地服务；不要直接双击 html 文件用浏览器打开（会因浏览器安全限制读不到数据）。

### ⚠️ 一个要知道的坑：报表显示 0 局 ≠ 你没打

解析器只读**当前**的 `Player.log`，而游戏一重启就会把旧日志改名存档成 `<uid>_<时间>.txt`。所以新会话还没打过拍卖时，报表会显示 0 局、或者局数突然变少。

- **你的完整战绩一直在 `生涯数据库/career.db` 里**，永久累积不会丢。想看历史请打开「生涯」页。
- 局数变少时程序会自动备份旧的 `result.json`，并提示你选择是否保留。

## 五、进阶：命令行用法（一般用不到）

在 exe 所在文件夹打开命令行，可以这样用：

```powershell
.\BidKing解析器.exe                      # 双击等价：解析 + 起服务 + 开网页
.\BidKing解析器.exe --serve              # 只启动本地服务
.\BidKing解析器.exe .\Player.log         # 指定日志文件
.\BidKing解析器.exe --uid 123456789      # 指定玩家 UID
.\BidKing解析器.exe --since 2026-05-10   # 只统计该日期之后
.\BidKing解析器.exe --wins-only          # 只统计拍到的场次
.\BidKing解析器.exe --csv result.csv     # 导出 CSV
.\BidKing解析器.exe --json my.json       # 指定输出的 JSON 文件名
```

也可以直接用 Python 源码（需 Python 3.10+）：

```powershell
python src/run_parser.py     # 一键解析并生成 result.json
python src/serve.py          # 启动本地服务（默认 8766 端口）
```

> 直接双击 html 文件用 `file://` 打开是读不到数据的，一定要通过 exe 或 `serve.py` 提供的地址访问。

## 六、已知限制

- **日志是实时增长的**：玩完一局后要点一次「实时刷新」才能看到最新战绩。
- **卡密自动确认**：估价器的「卡密验证」弹窗是 Python tkinter 写的，没有真正的按钮句柄，程序靠「后台按键」模拟回车。正常情况 0.01 秒内点掉、不影响你正在做的事；万一失败会提示「需要到电脑上手动点确定」。
- **没有「开箱记录」**：游戏日志里没有开箱相关的协议数据，所以开箱产出无法归因统计。
